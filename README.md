# Livestock Skin Disease Image Classifier

## Objective

The objective of this project is to classify livestock skin diseases from image data using Deep Learning techniques. The project compares the performance of a custom Convolutional Neural Network (CNN) model with a MobileNetV2 Transfer Learning model to identify skin disease categories accurately.

## Dataset

Dataset Name: Livestock Skin Disease Dataset(Dog's skin diseases (Image Dataset)

Dataset Link:
https://www.kaggle.com/datasets/youssefmohmmed/dogs-skin-diseases-image-dataset

### Dataset Description

* Image-based livestock skin disease dataset
* Multiple disease categories for classification
* Used for supervised image classification
* Images are resized and normalized before training

## Models Used

1. Convolutional Neural Network (CNN)
2. MobileNetV2 Transfer Learning Model
